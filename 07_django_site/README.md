# 🌐 Django-сайт: Персональная страница + Leap Year

## Описание
Учебный Django-проект из двух приложений: персональный сайт с динамическим контентом из БД и утилита для определения високосных годов с историей запросов и статистикой.

## Приложения

### 📄 mysite — Персональный сайт
- **5 моделей:** UserProfile, EducationProgram, Staff, Classmate, Page
- **Динамическая навигация:** модель Page с полями `nav_display` и `nav_position` — страницы добавляются/скрываются через админку
- **Загрузка изображений:** `ImageField` для фото профиля, однокурсников, преподавателей
- **Страницы:** главная (профиль), образовательная программа, преподаватели, однокурсники, динамические страницы
- **Шаблоны:** наследование (`navigation.html` → страницы), Bootstrap 5, Font Awesome, кастомный CSS

### 📅 leap_year — Проверка високосного года
- **Django Forms** для валидации ввода
- **Запись в БД:** каждый запрос сохраняется (год, является ли високосным, век, эра)
- **Агрегатные функции:** страница статистики с Count, Avg, Min, Max, StdDev, Sum по всем запросам
- **Поддержка годов до н. э.**

## Архитектура
```
project01/                  ← конфигурация проекта (settings, urls, wsgi)
├── mysite/                 ← приложение: персональный сайт
│   ├── models.py           ← 5 моделей с ImageField, URLField, TextField
│   ├── views.py            ← 5 view-функций, ORM-запросы
│   ├── urls.py             ← маршруты включая динамические (/page/<id>/)
│   ├── templates/          ← 6 HTML-шаблонов с наследованием
│   └── static/             ← CSS
├── leap_year/              ← приложение: проверка високосных годов
│   ├── models.py           ← YearData (год, високосный, век, эра)
│   ├── forms.py            ← YearForm (Django Forms)
│   ├── views.py            ← логика + агрегатные запросы (Avg, StdDev...)
│   └── templates/          ← 3 шаблона (ввод, результат, история)
└── manage.py
```
