## Проекты

### 1. 📈 [NLP: Индекс сентимента финансовых текстов](01_nlp_sentiment/)
Полный NLP-пайплайн: парсинг → предобработка (NLTK) → TF-IDF-векторизация → индекс сентимента → классификация тональности нейросетями (MLP, LSTM, RNN).

**Стек:** Python, NLTK, scikit-learn, TensorFlow/Keras, pandas, matplotlib

### 2. 🏛️ [Дипломная работа: Event Study](02_diploma_event_study/)
Влияние политических связей членов совета директоров на результаты деятельности российских компаний. Расчёт CAR/CAAR, панельные регрессии с полной диагностикой.

**Стек:** Python (statsmodels, eventstudy), R (plm, stargazer, lmtest, car, ggplot2)

### 3. 🎵 [ML: Предсказание успеха музыкальных треков](03_ml_music/)
Классификация и регрессия: KNN, логистическая регрессия, Random Forest, KMeans-кластеризация. Подбор гиперпараметров, кросс-валидация, ROC/AUC.

**Стек:** Python, scikit-learn, pandas, numpy, matplotlib, seaborn

### 4. 🤖 [AI Academic Task Planner — MVP](04_ai_task_planner/)
AI-планировщик учебных задач (RAG + LLM). Моя роль: концепция продукта, дизайн-документ, координация команды, тестирование (18 кейсов, эвристики Нильсена), реализация улучшений.

**Стек:** FastAPI, SQLite, Ollama, FAISS, LangChain, Docker

### 5. 🔍 [RAG-система на n8n](05_rag_system/)
Retrieval-Augmented Generation в no-code оркестраторе n8n: загрузка PDF → чанкинг → Cohere embeddings → поиск по vector store → генерация ответа через LLM.

**Стек:** n8n, Cohere Embeddings, Docker

### 6. 💱 [Telegram-бот: Курсы валют ЦБ РФ](06_telegram_bot/)
Асинхронный бот для просмотра динамики валютных курсов (с графиками) и конвертации валют по данным API ЦБ РФ. FSM-диалоги, генерация графиков в matplotlib, деплой на Amvera Cloud.

**Стек:** Python, aiogram 3.x, asyncio, pandas, matplotlib, Cloudinary API

### 7. 🌐 [Django-сайт: Персональная страница + Leap Year](07_django_site/)
Два Django-приложения: персональный сайт с 5 моделями, динамической навигацией и загрузкой изображений, а также утилита для определения високосных годов с Django Forms и агрегатной статистикой.

**Стек:** Python, Django 4.1, ORM, Bootstrap 5

### 8. 🕷️ [Парсеры финансовых данных](08_financial_parsers/)
Три парсера для сбора данных по облигациям: способ размещения (RusBonds, Playwright), кредитные рейтинги АКРА (Selenium с антидетектом) и Эксперт РА (requests). JSON-кэширование, промежуточное сохранение, имитация человека.

**Стек:** Python, Playwright, Selenium, BeautifulSoup, requests, pandas
