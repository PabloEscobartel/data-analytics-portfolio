# 🔍 RAG-система на n8n (домашнее задание)

## Описание
Retrieval-Augmented Generation система, построенная в no-code оркестраторе n8n. Загружает PDF-документ, разбивает на чанки, создаёт embeddings и позволяет задавать вопросы по содержимому через LLM.

## Воркфлоу

### RAG-индексация ([n8n_workflow_rag.json](n8n_workflow_rag.json))
Пайплайн обработки документа:
1. Извлечение текста из PDF
2. Разбиение на чанки
3. Генерация embeddings через Cohere (`embed-multilingual-v3.0`)
4. Сохранение в vector store для последующего поиска

### Чат-взаимодействие ([n8n_workflow_chat.json](n8n_workflow_chat.json))
Пайплайн ответа на вопрос:
1. Получение вопроса пользователя
2. Поиск релевантных чанков через embedding similarity
3. Формирование промпта с контекстом
4. Генерация ответа через LLM

## Стек
- **n8n** — оркестрация пайплайнов
- **Cohere** — multilingual embeddings
- **Docker** — контейнеризация n8n
