# 📈 NLP: Индекс сентимента финансовых текстов

## Описание
Построение индекса сентимента на основе текстовых данных с применением методов NLP и нейросетевых моделей для классификации тональности.

## Структура проекта

### Часть 1 — Обработка данных ([Barthel_Sentiment_Part_1.ipynb](Barthel_Sentiment_Part_1.ipynb))
- **Предобработка текста:** очистка от мусорных элементов, удаление стоп-слов (NLTK), стемминг и лемматизация
- **Анализ данных:** статистика длины текстов, обработка выбросов, частотный анализ (Counter)
- **Векторизация:** TF-IDF (scikit-learn) — преобразование текстов в числовые признаки
- **Индекс сентимента:** расчёт косинусного сходства (cosine_similarity) для оценки тональности
- **Создание датасетов:** 9 различных конфигураций (разные стратегии предобработки) для сравнения моделей

### Часть 2 — Обучение моделей ([Barthel_Sentiment_Part_2.ipynb](Barthel_Sentiment_Part_2.ipynb))
- **Три архитектуры нейросетей:**
  - MLP (Multilayer Perceptron) — базовый полносвязный классификатор
  - LSTM — для работы с последовательностями
  - RNN — базовая рекуррентная сеть
- **Обучение:** на всех 9 датасетах с визуализацией loss/accuracy
- **Сравнительный анализ:** выбор лучшей комбинации модель × датасет

## Стек
- **Python:** pandas, numpy, matplotlib, seaborn
- **NLP:** NLTK (tokenize, stem, stopwords), scikit-learn (TfidfVectorizer, cosine_similarity)
- **Deep Learning:** TensorFlow, Keras (Sequential, Dense, LSTM, SimpleRNN, Embedding)
- **Среда:** Google Colab
