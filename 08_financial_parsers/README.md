# 🕷️ Парсеры финансовых данных

## Описание
Набор парсеров для автоматизированного сбора финансовых данных из нескольких источников. Использовались для исследовательского проекта по анализу рынка облигаций в рамках магистратуры.

## Парсеры

### 📊 RusBonds — способ размещения облигаций
**Файл:** [`scrape_rusbonds_placement_method.py`](scrape_rusbonds_placement_method.py)

По списку ISIN из Excel автоматически собирает способ размещения каждой облигации с сайта RusBonds.

- **API-поиск** bond ID через `requests` (JSON API RusBonds)
- **Playwright** для парсинга страницы размещения (JS-рендеринг)
- **JSON-кэширование** — повторный запуск не дублирует запросы
- Промежуточное сохранение каждые 5 записей
- Антидетект: кастомный user-agent, рандомные паузы

### 🏦 АКРА — кредитные рейтинги облигаций
**Файл:** [`acra_parser.py`](acra_parser.py)

Для каждого ISIN находит рейтинг АКРА, актуальный на дату размещения облигации.

- **Selenium** с полной имитацией человека: посимвольный ввод, рандомные движения мыши, скроллы, паузы
- Антидетект: отключение `navigator.webdriver`, подмена плагинов и языков
- Поиск через строку поиска АКРА → парсинг истории рейтингов (BeautifulSoup)
- Алгоритм выбора: берёт последний рейтинг, присвоенный не позже даты размещения
- Длинные паузы каждые 25 запросов для избежания блокировки

### 📋 Эксперт РА — кредитные рейтинги облигаций
**Файл:** [`expertra_parser.py`](expertra_parser.py)

Аналогичная задача для рейтингового агентства Эксперт РА, но через `requests` (без браузера).

- CSRF-токен для авторизации поиска
- Парсинг таблиц истории рейтингов (BeautifulSoup + lxml)
- Фильтрация отозванных рейтингов
- Тот же алгоритм выбора рейтинга на дату размещения

### 💬 Парсинг комментариев по Bitcoin
**Файл:** [`crypto_comments_parser.ipynb`](crypto_comments_parser.ipynb)

Selenium-парсер комментариев по криптовалюте Bitcoin с заданными временными границами. Сбор данных в CSV с обработкой перезапусков.

## Общие паттерны проектирования
- **Кэширование** (JSON) во всех парсерах — устойчивость к обрывам, экономия времени
- **Промежуточное сохранение** — данные не теряются при падении
- **Антидетект** — имитация человека (Selenium), кастомные заголовки (requests)
- **Подтверждение запуска** — перед стартом парсинга показывает статистику и спрашивает подтверждение

## Стек
- **Python:** requests, pandas, BeautifulSoup, lxml
- **Браузерная автоматизация:** Playwright, Selenium
- **Данные:** JSON-кэш, Excel (openpyxl)
- **Антидетект:** webdriver-manager, CDP-команды, имитация поведения

## Запуск
```bash
pip install requests beautifulsoup4 pandas openpyxl lxml tqdm playwright selenium webdriver-manager

# RusBonds (требует авторизацию — заполните BEARER_TOKEN и COOKIES)
export RUSBONDS_BEARER_TOKEN="your_token"
python scrape_rusbonds_placement_method.py

# АКРА (откроется Chrome)
python acra_parser.py

# Эксперт РА (без браузера)
python expertra_parser.py
```

> ⚠️ Парсеры требуют авторизации на соответствующих сайтах. Токены и cookies не включены в репозиторий.
