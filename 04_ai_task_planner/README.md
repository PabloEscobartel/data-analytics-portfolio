# 🤖 AI Academic Task Planner — MVP (дизайн и тестирование)

## Описание
AI-планировщик учебных задач на базе RAG + LLM. Студент загружает PDF с заданием — система извлекает метаданные, генерирует план подзадач и адаптирует его под профиль пользователя.

Командный проект в рамках курса «Быстрое создание MVP в Data Science» (НИУ ВШЭ, 2026).

**Моя роль:** автор концепции продукта, разработка дизайн-документа (user flow, архитектура, UI/UX), координация команды, полный цикл тестирования, реализация улучшений по результатам.

## Что сделано

### Дизайн-документ
- User Flow: онбординг → главный экран → загрузка файла → анализ документа → генерация плана → работа с задачами
- Архитектура: FastAPI + SQLite + LLM API (Ollama/Qwen) + FAISS
- UI/UX-видение: макеты экранов, фокус-режим, система мотивации (streaks, прогресс)
- Спецификация JSON-контракта между LLM и фронтендом

### Тестирование ([TESTS.md](TESTS.md))
- **18 тест-кейсов:** загрузка файлов (7), LLM-ответы (4), действия с задачами (4), база данных (3)
- **Эвристическая оценка UI/UX** по 10 эвристикам Нильсена
- **Пользовательское тестирование:** интервью с 4 персонами из целевой аудитории
- Итог: 6 passed, 12 failed/warn — выявлены критические баги

### Улучшения ([IMPROVEMENTS.md](IMPROVEMENTS.md))
Реализованные исправления по результатам тестирования:
- Кнопка «Сложно» — автоматическая декомпозиция задач через LLM
- Устойчивый парсинг JSON-ответов (многоуровневая стратегия + regex fallback)
- Кнопка «Позже» для переноса задач на следующий день
- Визуальный feedback при действиях пользователя

## Стек проекта
FastAPI, SQLite, Ollama (Qwen 2.5), FAISS, LangChain, Jinja2 + Tailwind, Docker
