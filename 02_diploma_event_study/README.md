# 🏛️ Дипломная работа: Event Study

## Тема
**«Влияние политических связей членов совета директоров на результаты деятельности компаний»**

Бакалаврская дипломная работа (НИУ ВШЭ, 2025). Победитель конкурса студенческих НИР ВШЭ в направлении «Финансы» (2024).

## Описание
Исследование влияния политических связей на рыночную стоимость российских компаний через призму event study методологии и эконометрического моделирования.

## Структура проекта

### Event Study — Python
- **[Diploma.ipynb](Diploma.ipynb)** — расчёт аномальной доходности (AR), кумулятивной аномальной доходности (CAR) для отдельных событий. Market Model: оценка alpha/beta на estimation window, расчёт predicted returns на event window
- **[DiplomaCAAR.ipynb](DiplomaCAAR.ipynb)** — агрегация: расчёт CAAR (Cumulative Average Abnormal Return) по всей выборке, визуализация

### Эконометрический анализ — R
- **[regression_analysis.R](regression_analysis.R)** — полный цикл регрессионного анализа (1500+ строк):
  - Обработка выбросов
  - Корреляционный анализ и визуализация (corrplot, ggplot2)
  - Панельные регрессии (plm) для подвыборок: до/после 2014, собрания/рассылки
  - Диагностика моделей (условия Гаусса-Маркова):
    - Спецификация (RESET-тест)
    - Гомоскедастичность (Бройша-Пагана)
    - Автокорреляция (Дарбина-Уотсона)
    - Мультиколлинеарность (VIF)
  - Финальные модели с робастными стандартными ошибками
  - Вывод через stargazer

## Стек
- **Python:** pandas, numpy, statsmodels, eventstudy, matplotlib
- **R:** dplyr, tidyr, ggplot2, plm, stargazer, car, lmtest, corrplot, AER, MASS
- **Данные:** логарифмические доходности российских компаний, индекс MOEX
